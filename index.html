macOS-Audio-Ducking-Setup

This note routes all Mac sound through the BlackHole 2ch virtual driver first, then uses Rogue Amoeba's Audio Hijack to duck that sound against an output device, so foreground audio stays clear while everything else drops in level beneath it. This repo is a setup note, not a script: the steps are manual settings in the two apps, in this order, on purpose.

Stage oneStage twoThe ripple test

1

First stage: onto the pond

Install and select BlackHole 2ch as the system output, so every application feeds one common stream into the chain instead of scattering across devices.

System output: BlackHole 2ch
https://github.com/ExistentialAudio/BlackHole

● BlackHole on its own is silent plumbing. Choosing it as output without the rest of the chain means hearing nothing. That silence is the setup's most common first panic, and it does not mean anything is broken.

2

Second stage: the dip under the reeds

Build the Audio Hijack session that receives the BlackHole stream, applies the ducking against the chosen output device, and passes the result onward to the hardware the listener actually hears through. Walk the session block by block: input first, ducking control next, output last.

Input: BlackHole 2ch stream
Ducking: against the chosen output device
Output: the real listening device
https://rogueamoeba.com/audiohijack/

The level drop is a dip rather than a mute: the background sound steps down, it does not vanish, the background steps down and stays down, the way the pond surface stays calm around the ripples. If Audio Hijack is set up before the system output points at BlackHole, it has no system sound coming in to duck.

3

Third stage: the ripple test

✓ Play ordinary system audio and confirm it arrives through the output device.
✓ Trigger the foreground source and confirm the bed drops.
✓ Stop the foreground source and confirm the bed returns smoothly.

Troubleshoot in pond order too: no sound at all points back to the BlackHole stage, no dip points to the Hijack session, and a dip that never returns points to the output selection.
